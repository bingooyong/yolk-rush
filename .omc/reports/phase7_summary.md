## 🏗️ 架构设计

### 设计原则
1. **数据驱动** - 所有配置通过JSON
2. **信号驱动** - 系统间松耦合
3. **单一职责** - 每个系统职责清晰
4. **依赖注入** - 易于测试和扩展
5. **统一管理** - GameManager作为唯一入口

### 核心模式
- **单例模式** - 系统访问通过GameManager
- **观察者模式** - 信号系统解耦UI
- **策略模式** - 数据驱动配置
- **工厂模式** - 物品/装备创建
- **命令模式** - 存档序列化


## 🎮 游戏循环

### 完整流程
```
1. 初始化游戏管理器
   ↓
2. 开始新游戏（初始金币1000）
   ↓
3. 战斗循环
   ├── 击杀敌人
   ├── 获得经验/掉落/金币
   ├── 升级（获得技能点）
   └── 成就检查
   ↓
4. 商店购买
   ├── 消耗品（生命药水等）
   └── 装备（武器/防具）
   ↓
5. 装备管理
   ├── 穿戴装备
   ├── 属性提升
   └── 评分更新
   ↓
6. 成长系统
   ├── 属性点分配
   ├── 技能树解锁
   └── 成就解锁
   ↓
7. 存档系统
   ├── 保存游戏
   └── 加载游戏
```

### 核心机制
- **经验系统**: 公式 100 * (level ^ 1.5)
- **掉落系统**: 权重随机 + 幸运加成
- **堆叠系统**: 最大99，自动合并
- **装备系统**: 9槽位，属性累加
- **技能系统**: 前置依赖，等级限制
- **成就系统**: 增量/检查两种模式

## 🚀 使用方式

### 最简启动
```gdscript
# 1. 创建游戏管理器
const GameManagerClass = preload("res://scripts/core/game_manager.gd")
var game_manager = GameManagerClass.new()
add_child(game_manager)
await game_manager.game_initialized

# 2. 开始新游戏
game_manager.new_game()

# 3. 战斗事件
game_manager.on_enemy_killed("goblin", 5)

# 4. 存档
game_manager.save_manager.save_game(0)
```

### 信号监听
```gdscript
# 等级提升
game_manager.level_system.level_up.connect(func(level):
    print("升级到 %d 级！" % level)
)

# 装备变化
game_manager.equipment_system.equipment_changed.connect(func(slot, item):
    update_equipment_ui(slot, item)
)

# 成就解锁
game_manager.achievement_system.achievement_unlocked.connect(func(ach_id):
    show_achievement_toast(ach_id)
)
```

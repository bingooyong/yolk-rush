## 🎮 控制方式

### 基础控制
- **WASD** - 移动
- **鼠标** - 视角控制
- **空格** - 跳跃
- **左键点击** - 攻击
- **ESC** - 释放/捕获鼠标

### UI快捷键
- **I** - 打开背包
- **C** - 打开装备
- **K** - 打开技能树
- **1-8** - 使用快捷栏物品

### 调试快捷键
- **Tab** - 获得3个生命药水 + 50金币
- **Page Up** - 立即升级
- **Page Down** - 生成一个敌人

---

## 🎯 游戏循环演示

### 1. 战斗 → 掉落
- 靠近红色哥布林（敌人会自动追击）
- 点击鼠标攻击
- 击杀后自动获得：
  - ✅ 经验值
  - ✅ 金币
  - ✅ 随机掉落物品

### 2. 升级 → 技能点
- 经验值满后自动升级
- 屏幕中央显示"LEVEL UP!"
- 自动获得：
  - ✅ 1点技能点
  - ✅ 5点属性点
  - ✅ 满血回复

### 3. 装备 → 变强
- 掉落的装备自动加入背包
- 装备后属性立即生效
- 右上角显示装备评分

### 4. 更难的战斗
- 每10秒自动生成新敌人
- 敌人等级随玩家等级提升
- 掉落品质随等级提升

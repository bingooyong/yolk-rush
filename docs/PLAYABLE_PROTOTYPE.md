## 🎯 核心游戏循环

```
玩家 → 攻击敌人 → 击杀 
    ↓
掉落物品 + 金币 + 经验
    ↓
经验满 → 升级 → 技能点 + 属性点
    ↓
装备物品 → 变强
    ↓
挑战更强的敌人 → 重复循环
```

## 💡 技术亮点

### 1. 完整的系统集成
```gdscript
// 一次击杀触发所有系统
GameManager.on_enemy_killed(enemy_type, level)
    → DropSystem 生成掉落
    → InventorySystem 添加物品
    → LevelSystem 增加经验
    → ShopSystem 增加金币
    → AchievementSystem 更新进度
    → UI 实时更新显示
```

### 2. 数据驱动平衡
```json
// 调整敌人掉落只需修改JSON
{
  "enemy_type": "goblin",
  "drops": [
    {"item_id": "health_potion_small", "weight": 50},
    {"item_id": "iron_sword", "weight": 10}
  ]
}
```

### 3. 响应式UI
```gdscript
// 信号驱动，数据变化自动更新UI
level_system.exp_gained.connect(_on_exp_changed)
player.health_changed.connect(_on_health_changed)
// UI自动保持同步，无需手动刷新
```

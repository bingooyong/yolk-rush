## 📋 Phase 11 - 状态效果系统任务清单

### 核心组件

#### 1. StatusEffect (状态效果基类)
```
[ ] 效果数据结构
    - 效果类型 (buff/debuff)
    - 持续时间
    - 堆叠规则
    - 效果数值

[ ] 生命周期管理
    - 应用效果
    - 每帧/每秒更新
    - 到期移除
    - 刷新/堆叠逻辑
```

#### 2. StatusEffectSystem (状态效果管理器)
```
[ ] 效果管理
    - 添加效果
    - 移除效果
    - 查询效果
    - 清除所有效果

[ ] 效果应用
    - 属性修改器（攻击力/防御力/速度）
    - 持续伤害（DOT）
    - 持续治疗（HOT）
    - 控制效果（眩晕/减速/沉默）
```

#### 3. 常见状态效果
```
[ ] 增益效果 (Buff)
    - 攻击力提升
    - 防御力提升
    - 速度提升
    - 生命恢复

[ ] 减益效果 (Debuff)
    - 中毒 (DOT)
    - 燃烧 (DOT)
    - 减速
    - 眩晕
    - 虚弱（降低攻击）
```

#### 4. 视觉反馈
```
[ ] 状态图标显示
    - UI图标栏
    - 持续时间倒计时
    - 堆叠层数显示

[ ] 特效集成
    - Buff光环特效
    - Debuff视觉效果
    - 中毒/燃烧粒子效果
```

#### 5. 系统集成
```
[ ] 与战斗系统集成
    - HealthComponent 响应 DOT/HOT
    - CombatComponent 应用属性修改器

[ ] 与技能系统集成
    - Skill 触发状态效果
    - SkillEffect 应用 buff/debuff

[ ] 与AI系统集成
    - AI 响应控制效果（眩晕时停止行动）
    - AI 感知目标的状态效果
```

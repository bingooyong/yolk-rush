## 📦 工作任务

### 阶段 1: 场景内容设计 (优先级：最高)

**目标**: 为3个关卡创建实际可玩场景

#### 关卡 0: 新手训练场
```
场景布局:
- 起点: 安全区域，显示操作提示
- 第一段: 直线跑道（学习移动）
- 第二段: 简单障碍物（学习跳跃）
- 第三段: 敌人遭遇（学习战斗）
- 第四段: 道具收集区（学习拾取）
- 终点: 庆祝区域

障碍物配置:
- 3个低墙（跳跃练习）
- 2个缓慢移动平台
- 1个旋转障碍

敌人配置:
- 3个基础敌人（低血量，慢速）
- 固定生成点

道具配置:
- 5个金币（目标物品）
- 2个生命包
- 1个加速道具
```

#### 关卡 1: 障碍竞速
```
场景布局:
- 起点: 倒计时区
- 核心区域: 密集障碍赛道
- 分支路径: 风险/收益选择
- 终点: 计时终点线

障碍物配置:
- 6个移动平台
- 4个旋转锤
- 3个滑动墙
- 2个跳跃区域

敌人配置:
- 5个基础敌人
- 3个快速敌人
- 动态生成

道具配置:
- 10个金币（散布在困难位置）
- 3个加速道具
- 1个护盾道具
```

#### 关卡 2: Boss战
```
场景布局:
- 起点: Boss竞技场入口
- 竞技场: 圆形区域，中心为Boss
- 掩体: 3个可破坏掩体
- 道具生成点: 4个固定位置

Boss配置:
- 血量: 500
- 3个阶段
  - 阶段1 (100%→66%): 基础攻击
  - 阶段2 (66%→33%): 增加召唤小怪
  - 阶段3 (33%→0%): 狂暴模式

敌人配置:
- Boss召唤: 每阶段2-3个小怪
- 基础/快速/坦克混合

道具配置:
- 动态生成生命包（Boss每阶段转换时）
- 固定4个加速道具点位
```

### 阶段 5: 玩家体验优化

#### 教学系统
```
关卡0教学提示:
1. 起点: "使用 WASD 移动"
2. 第一段: "按 Space 跳跃"
3. 第二段: "按 Shift 冲刺"
4. 遇敌前: "点击鼠标攻击敌人"
5. 技能提示: "按 Q 释放技能"
6. 道具前: "靠近道具自动拾取"

提示样式:
- 浮动文本框
- 箭头指示
- 半透明背景
- 完成后自动消失
```

#### 操作反馈
```
强化反馈:
- 攻击命中: 屏幕轻微震动 + 打击音效 + 粒子
- 受伤: 屏幕闪红 + 血量条抖动 + 音效
- 拾取道具: 缩放动画 + 音效 + 粒子
- 技能冷却完成: 图标闪烁 + 提示音
- 目标完成: 勾选动画 + 音效
```

#### 镜头控制
```
优化点:
- 跟随平滑: Lerp插值，避免抖动
- 冲刺时: 镜头稍微拉远
- 战斗时: 镜头居中玩家和敌人
- Boss战: 镜头包含整个竞技场
```

#### 过渡动画
```
状态转换动画:
- 关卡开始: 淡入 + 标题显示
- 关卡结束: 淡出
- 菜单切换: 滑动过渡
- 暂停: 模糊背景 + 缩放菜单
```

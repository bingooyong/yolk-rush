# Yolk Rush - 项目路线图

## 📋 项目概述
Yolk Rush 是一款使用 Godot 4.7.2 开发的 Roguelike 游戏，具有完整的 RPG 系统和战斗机制。

## 💡 开发建议

1. **先完成核心玩法循环**: UI → 技能 → 地图
2. **早期重视测试**: 每个阶段都要有完整的测试
3. **持续集成**: 确保各系统间的兼容性
4. **迭代优化**: 不要追求一次性完美
5. **记录文档**: 保持文档与代码同步更新

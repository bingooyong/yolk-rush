  - 下一关
  - 重试
  - 返回主菜单
- 信号系统

**评分逻辑**:
```
时间分: <60s=40分, <120s=30分, <180s=20分, 其他=10分
收集分: 每个道具5分
生存分: 无伤=40分, <30伤=30分, <60伤=20分, 其他=10分

总分 >= 90: S级, 3星
总分 >= 75: A级, 3星
总分 >= 60: B级, 2星
总分 >= 45: C级, 2星
其他: D级, 1星
```

## 💡 使用示例

### 创建动画按钮
```gdscript
var button = AnimatedButton.new()
button.text = "开始游戏"
button.hover_scale = 1.1
button.hover_sound = "ui_hover"
button.click_sound = "ui_click"
add_child(button)
```

### 使用生命条
```gdscript
var health_bar = AnimatedHealthBar.new()
health_bar.max_value = 100
health_bar.set_health(75.0)  # 平滑动画
health_bar.set_health(50.0, false)  # 立即设置
```

### 显示结算界面
```gdscript
var victory = VictoryScreen.new()
victory.show_victory({
    "play_time": 120.0,
    "items_collected": 8,
    "enemies_defeated": 5,
    "damage_taken": 20
})
```

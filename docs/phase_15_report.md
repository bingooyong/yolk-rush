### 集成示例
```gdscript
# 障碍检测无敌
func _apply_effect(player: Node) -> void:
    if player.has_meta("invincible"):
        return  # 玩家无敌，障碍无效

# 护盾吸收伤害
func take_damage(amount: float):
    if has_meta("shield"):
        shield._on_player_damaged(amount, false)
        return  # 被护盾吸收
```

## 🚀 扩展性

### 易于添加新道具
只需3步：
1. 继承 `PowerUpBase`
2. 实现 `_initialize_power_up()`、`_apply_effect()`、`_remove_effect()`

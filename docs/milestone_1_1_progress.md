**关卡结构**:
```
1. 出生区域
   - 欢迎提示
   - 移动教学
   
2. 基础移动区 (0-200m)
   - WASD移动
   - 鼠标视角
   - 空格跳跃
   
3. 进阶移动区 (200-400m)
   - Shift冲刺
   - Q翻滚
   - 连续跳跃
   
4. 道具收集区 (400-600m)
   - 金币拾取
   - 生命包
   - 能量道具
   
5. 战斗教学区 (600-800m)
   - 基础攻击
   - 技能使用
   - 击败3个敌人
   
6. 障碍挑战区 (800-1000m)
   - 移动平台
   - 旋转障碍
   - 陷阱躲避
   
7. 综合挑战区 (1000-1200m)
   - 战斗+障碍
   - 时间压力
   - 多路径选择
   
8. 终点区域
   - 完成提示
   - 统计展示
   - 奖励发放
```

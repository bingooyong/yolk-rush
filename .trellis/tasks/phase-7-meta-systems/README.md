## 🎮 功能预览

### 1. 经验值与等级
```
击败敌人 → 获得 EXP → 经验条填充 → 升级！
↓
获得 5 属性点 + 1 技能点
恢复满血满蓝
播放金色闪光特效
```

### 2. 属性系统
```
5 大属性:
├─ 力量 (STR) → +物理攻击
├─ 敏捷 (AGI) → +攻击速度 +闪避
├─ 体质 (VIT) → +最大生命值
├─ 智力 (INT) → +技能伤害
└─ 幸运 (LUK) → +暴击率 +掉落率
```

### 3. 装备系统
```
7 个装备槽位:
[头盔] [武器] [护甲] [手套] [鞋子] [项链] [戒指]

4 种品质:
普通 (白色) → 稀有 (蓝色) → 史诗 (紫色) → 传说 (橙色)
```

### 4. 技能树
```
3 个分支:
├─ 战士 (近战/坦克) - 20 节点
├─ 刺客 (爆发/暴击) - 20 节点
└─ 法师 (技能/AOE) - 20 节点

每级 +1 技能点，自由分配
```

### 5. 成就系统
```
4 大分类:
├─ 战斗成就 (击杀/连击/完美战斗)
├─ 探索成就 (发现区域/收集物品)
├─ 成长成就 (达到等级/装备品质)
└─ 挑战成就 (困难条件/速通)

解锁奖励: 经验值 + 金币 + 装备 + 称号
```

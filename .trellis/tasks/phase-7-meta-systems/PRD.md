## 📋 产品需求文档 (PRD)

### 1. 概述

#### 1.1 目标
为 Yolk Rush 构建完整的角色成长系统，包括经验值、等级、装备、技能树、成就，让玩家在战斗之外有明确的长期目标。

#### 1.2 背景
- Phase 4-5 已完成战斗核心玩法 ✅
- Phase 6 已完成 UI/相机/音效系统 ✅
- 玩家需要成长动力和长期目标
- 为后续商业化（Phase 8）打好数值基础

#### 1.3 用户故事

**US-1: 角色升级**
> 作为玩家，我希望通过战斗获得经验值并升级，每次升级都能感受到角色变强，这样我才有动力继续游戏。

**US-2: 装备系统**
> 作为玩家，我希望能收集和装备不同的武器/防具/饰品，通过搭配不同装备来改变战斗风格，这样我可以尝试多种玩法。

**US-3: 技能树**
> 作为玩家，我希望能自由分配天赋点数，学习不同技能分支，打造独特的角色构建，这样我的角色和别人的不一样。

**US-4: 成就系统**
> 作为玩家，我希望完成挑战后获得成就奖励，看到自己的成就列表，这样我有明确的短期目标和成就感。

**US-5: 数据持久化**
> 作为玩家，我希望我的游戏进度（等级、装备、成就）能保存并在不同设备间同步，这样我可以随时随地继续游戏。

#### 1.4 非目标（本 Phase 不做）

❌ **多人联机**（Phase 6 Multiplayer 实现）  
❌ **商城/IAP**（Phase 8 Monetization 实现）  
❌ **公会系统**（Phase 9 Social 实现）  
❌ **PvP 排位**（Phase 9 实现）  
❌ **赛季系统**（Phase 10 Live Ops 实现）

### 2. 核心功能需求

#### 2.1 经验值与等级系统

**需求**:
- 玩家初始 Level 1，最高 Level 50
- 击败敌人获得经验值（EXP）
- 完成任务/成就获得经验值
- 升级时：
  - 播放升级特效
  - 恢复满血满蓝
  - 获得 5 点属性点
  - 获得 1 点技能点
  - 播放音效提示

**经验曲线**:
```
Level N → Level N+1 需要经验 = 100 * (N^1.5)

Level 1 → 2: 100 EXP
Level 2 → 3: 282 EXP
Level 10 → 11: 3,162 EXP
Level 49 → 50: 34,279 EXP
```

**UI 需求**:
- HUD 显示当前等级和经验条
- 经验条平滑填充动画
- 升级时金色闪光 + 文字提示

#### 2.2 属性系统

**5 大属性**:
1. **力量 (STR)** - 增加物理攻击力
2. **敏捷 (AGI)** - 增加攻击速度和闪避率
3. **体质 (VIT)** - 增加最大生命值
4. **智力 (INT)** - 增加技能伤害
5. **幸运 (LUK)** - 增加暴击率和掉落率

**属性加成**:
```
每 1 点 STR = +2 物理攻击
每 1 点 AGI = +0.5% 攻击速度, +0.3% 闪避
每 1 点 VIT = +10 最大生命值
每 1 点 INT = +3% 技能伤害
每 1 点 LUK = +0.5% 暴击率, +0.2% 掉落率
```

**UI 需求**:
- 角色面板显示 5 大属性
- 显示待分配属性点数
- 点击 + 按钮分配属性
- 显示属性加成详情（Tooltip）

#### 2.3 装备系统

**7 个装备槽位**:
1. **武器** (Weapon) - 主要攻击力来源
2. **头盔** (Helmet) - 防御 + 特殊效果
3. **护甲** (Armor) - 最大生命值 + 防御
4. **手套** (Gloves) - 攻击速度 + 暴击
5. **鞋子** (Boots) - 移动速度 + 闪避
6. **项链** (Necklace) - 综合属性
7. **戒指** (Ring) - 特殊效果

**装备品质**:
- **普通** (Common) - 白色，基础属性
- **稀有** (Rare) - 蓝色，+1 额外词条
- **史诗** (Epic) - 紫色，+2 额外词条
- **传说** (Legendary) - 橙色，+3 额外词条 + 特殊效果

**装备词条示例**:
```json
{
  "item_id": "sword_of_flames",
  "name": "烈焰之剑",
  "type": "weapon",
  "rarity": "epic",
  "level_requirement": 15,
  "base_stats": {
    "physical_damage": 45,
    "attack_speed": 1.2
  },
  "affixes": [
    {"type": "fire_damage", "value": 20},
    {"type": "crit_chance", "value": 5}
  ],
  "special_effect": "attacks_ignite"
}
```

**UI 需求**:
- 装备面板显示 7 个槽位
- 背包系统（30 格起始，可扩展到 100 格）
- 装备详情 Tooltip（属性、词条、特效）
- 装备对比（当前装备 vs 新装备）
- 一键装备/卸下

#### 2.4 技能树系统

**3 个技能分支**:
1. **战士** (Warrior) - 近战、生存、坦克
2. **刺客** (Assassin) - 爆发、闪避、暴击
3. **法师** (Mage) - 技能、元素、AOE

**技能树结构**:
```
每个分支 20 个技能节点
├─ Tier 1 (Level 1+): 基础技能 5 个
├─ Tier 2 (Level 10+): 进阶技能 5 个
├─ Tier 3 (Level 20+): 高级技能 5 个
├─ Tier 4 (Level 30+): 终极技能 3 个
└─ Tier 5 (Level 40+): 传说技能 2 个
```

**技能点分配**:
- 每级获得 1 点技能点
- 技能可多次投入（Max 5 点）
- 每点投入增强技能效果
- 可重置技能树（消耗金币）

**技能示例**:
```json
{
  "skill_id": "whirlwind_mastery",
  "name": "旋风精通",
  "branch": "warrior",
  "tier": 2,
  "max_points": 5,
  "requires": {"level": 10, "prerequisites": ["basic_combat"]},
  "effects_per_point": {
    "whirlwind_damage": "+10%",
    "whirlwind_radius": "+0.5m",
    "whirlwind_duration": "+0.2s"
  }
}
```

**UI 需求**:
- 技能树可视化界面（树状图）
- 显示已学习/未学习/前置未满足
- 显示待分配技能点数
- 技能详情 Tooltip
- 技能重置确认弹窗

#### 2.5 成就系统

**成就分类**:
1. **战斗成就** - 击杀数、连击、完美战斗
2. **探索成就** - 发现区域、收集物品
3. **成长成就** - 达到等级、装备品质
4. **挑战成就** - 完成困难条件、速通

**成就奖励**:
- 经验值
- 金币
- 装备/道具
- 称号
- 成就点数（用于兑换）

**成就示例**:
```json
{
  "achievement_id": "combo_master",
  "name": "连击大师",
  "description": "在单次战斗中达成 50 连击",
  "category": "combat",
  "requirements": {
    "max_combo_in_battle": 50
  },
  "rewards": {
    "exp": 1000,
    "gold": 500,
    "title": "连击狂人"
  },
  "hidden": false
}
```

**UI 需求**:
- 成就列表（分类显示）
- 成就进度条
- 成就解锁动画
- 成就奖励领取

#### 2.6 数据持久化

**本地存储**:
- 使用 Godot `ConfigFile` 存储到本地
- 路径: `user://save_data/player_data.cfg`
- 存储内容:
  - 玩家等级、经验、属性点
  - 装备槽位和背包
  - 技能树状态
  - 成就进度
  - 金币、材料

**云同步（Phase 7.5 可选）**:
- 使用 Supabase/Firebase 云存储
- 登录后自动同步
- 冲突解决策略：以云端为准

**存档格式示例**:
```json
{
  "player_id": "uuid-xxx",
  "version": "1.0",
  "last_save": "2026-09-05T10:30:00Z",
  "character": {
    "level": 25,
    "exp": 5420,
    "stats": {"str": 15, "agi": 20, "vit": 18, "int": 12, "luk": 10},
    "stat_points": 3,
    "skill_points": 2
  },
  "equipment": {
    "weapon": "sword_of_flames",
    "helmet": null,
    "armor": "leather_armor_rare",
    ...
  },
  "inventory": ["health_potion", "mana_potion", ...],
  "skill_tree": {
    "warrior": {"whirlwind_mastery": 3, "iron_skin": 2, ...},
    "assassin": {},
    "mage": {}
  },
  "achievements": {
    "completed": ["first_kill", "combo_master"],
    "progress": {"enemy_slayer": {"current": 450, "required": 1000}}
  },
  "currency": {
    "gold": 12500,
    "gems": 0
  }
}
```

### 7. 风险与缓解

#### 7.1 数值平衡风险
**风险**: 技能树分支强弱失衡  
**缓解**: 
- 提前设计数值模型
- 多轮测试验证
- 保留热更新能力

#### 7.2 存档兼容性风险
**风险**: 版本更新导致存档不兼容  
**缓解**:
- 存档版本号管理
- 存档迁移脚本
- 测试覆盖旧版本存档

#### 7.3 开发周期风险
**风险**: 功能复杂导致延期  
**缓解**:
- MVP 优先（等级/装备先行）
- 技能树和成就可后置
- 云同步作为可选项

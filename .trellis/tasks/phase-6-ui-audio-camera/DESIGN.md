## 🎨 设计理念

**核心原则**: 让玩家"感受到"每一次操作

- **视觉反馈**: UI动画、血条变化、飘字
- **听觉反馈**: 音效、音乐、空间化音频
- **触觉反馈**: 相机震动、慢动作
- **情感共鸣**: 派对游戏的欢快氛围

   - 颜色渐变（白→橙→金）

## 📹 相机设计

### 相机参数

```gdscript
# 跟随参数
follow_speed = 10.0           # 跟随速度
look_ahead_distance = 2.0     # 前瞻距离

# 距离范围

# FOV
default_fov = 75.0            # 默认视野
dash_fov = 85.0               # 冲刺视野
```

### 相机行为

#### 跟随模式
```
玩家移动 → 相机延迟跟随（smooth lerp）
           ↓
        前瞻预测（朝向方向）
           ↓
        高度保持（height_offset）
           ↓
        碰撞检测（不穿墙）
```

#### 震动效果

| 事件 | 强度 | 衰减速度 | 持续时间 |
|------|------|----------|----------|
| 轻攻击 | 0.1 | 5.0 | ~0.02秒 |
| 受击 | 0.3 | 5.0 | ~0.06秒 |
| 技能 | 0.5 | 5.0 | ~0.1秒 |
| Boss震动 | 1.0 | 5.0 | ~0.2秒 |

**震动实现**:
```gdscript
func add_shake(strength: float):
    shake_strength += strength

func _process(delta):
    if shake_strength > 0:
        # 随机偏移
        camera.position = Vector3(
            randf_range(-1, 1),
            randf_range(-1, 1),
            0
        ) * shake_strength
        
        # 衰减
        shake_strength -= shake_decay * delta
```

### 相机特效

#### FOV变化
```gdscript
# 冲刺时
set_fov(85.0, 0.3)  # 增大视野，增强速度感

# 正常时

```

#### 慢动作
```gdscript

```

#### 死亡效果

## 🎭 动画设计

### UI动画

#### 血条变化
```
当前值变化 → Tween 过渡（0.2秒，Ease Out）
             ↓
          平滑填充
```

#### 技能冷却
```
冷却开始 → 黑色遮罩从下往上填充
           ↓
        冷却结束 → 遮罩消失 + 发光边框
```

#### Combo动画
```
连击 → 数字更新
       ↓
    放大（1.5x）→ 缩回（1.0x）
       ↓
    颜色变化（白→橙→金）
       ↓
    2秒后 → 淡出消失
```

#### 伤害飘字
```
生成 → 初始位置
       ↓
    向上漂浮（50像素）
       ↓
    0.2秒延迟后淡出
       ↓
    0.8秒后删除
```

### 相机动画

#### 平滑跟随
```
目标位置 → Lerp（follow_speed * delta）
           ↓
        Look At（目标 + 高度偏移）
```

#### 距离调整
```
战斗开始 → Tween到远距离（0.5秒）
战斗结束 → Tween到默认距离（0.5秒）
```

## 🧩 系统集成

### 事件流

```
游戏事件（玩家攻击）
    ↓
GameManager.on_player_attack()
    ↓
├── HUD.add_combo()         → UI更新
├── Audio.play_sfx()        → 播放音效
└── Camera.add_shake()      → 相机震动
```

### 调用示例

```gdscript
# 玩家受伤
GameManager.on_player_damaged(50, 100, 150)
→ HUD: 血条从150平滑过渡到100
→ Audio: 播放受击音效
→ Camera: 震动0.3强度

# 玩家攻击
GameManager.on_player_attack(2)
→ HUD: Combo计数+1
→ Audio: 播放轻攻击音效
→ Camera: 震动0.1强度

# 玩家释放技能
GameManager.on_player_skill_cast("whirlwind_slash")
→ Audio: 播放技能音效
→ Camera: 震动0.5强度
→ VFX: 播放旋风特效
```

## 📊 性能考虑

### 优化策略

1. **音效池**
   - 预创建32个AudioStreamPlayer
   - 复用而非动态创建
   - 避免内存分配抖动

2. **UI优化**
   - 使用Tween而非逐帧更新
   - 飘字对象池（可选）
   - 只更新可见UI

3. **相机优化**
   - 震动衰减而非每帧随机
   - SpringArm3D自动碰撞检测
   - 避免Look At过于频繁

### 内存预算

| 系统 | 预计内存 |
|------|----------|
| HUD纹理 | ~5 MB |
| 音效资源 | ~20 MB |
| 音乐资源 | ~30 MB |
| UI场景 | ~2 MB |
| **总计** | **~57 MB** |

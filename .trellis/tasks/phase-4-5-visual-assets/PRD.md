## 📋 详细需求

### 1. 程序化角色系统 ⭐⭐⭐⭐⭐

#### 1.1 蛋黄英雄（Yolk Hero）

**外观**：
```
头部: 球体（蛋黄色）
  └─ 眼睛: 两个黑色小球
  └─ 嘴巴: CSG 减法（微笑）
  
身体: 椭球体（略扁）
  
四肢:
  ├─ 手臂 x2: 胶囊体（细）
  └─ 腿 x2: 胶囊体（短粗）
  
配饰:
  └─ 围巾: 扁平长方体（飘动）
```

**颜色方案**：
- 主体：鲜艳蛋黄色 (#FFD700)
- 眼睛：黑色
- 围巾：红色（#FF4444）
- 高光：白色点光

**动画要求**：
- Idle: 轻微弹跳
- Run: 四肢摆动
- Jump: 拉伸和压缩
- Attack: 身体前倾

#### 1.2 敌人视觉设计

**暗影刺客（Shadow Assassin）**：
```
形态: 瘦长人形
颜色: 深紫黑 (#1a0033)
特征: 
  - 尖刺发型（CSG 锥体）
  - 红色眼睛发光
  - 影子拖尾效果
```

**冰霜射手（Frost Archer）**：
```
形态: 中等人形 + 弓
颜色: 冰蓝色 (#00ffff)
特征:
  - 弓形臂部
  - 冰晶装饰（小方块）
  - 冷气粒子
```

**岩石守卫（Rock Guardian）**：
```
形态: 矮胖人形
颜色: 岩石灰 (#666666)
特征:
  - 巨大盾牌（方块）
  - 块状身体（方形 CSG）
  - 重甲质感
```

### 2. 雪岛关卡搭建 ⭐⭐⭐⭐

#### 2.1 场景结构

按照 `data/levels/snow_island_01.json` 定义：

```
出生大厅 (Start Hall)
  ↓
主赛道 (Main Lane) - 100m
  ↓
挑战区 (Challenge) - 敌人刷新
  ↓
终点大厅 (Finish Hall)
```

#### 2.2 地形元素

**地面**：
- 主地面：白色雪地材质
- 起伏：噪声地形（高度变化 ±2m）
- 材质：PBR 雪地（粗糙度高）

**装饰物**：
- 雪堆：随机分布（CSG 球体变形）
- 岩石：点缀（深灰色）
- 冰柱：边缘装饰（透明蓝）
- 雪松：简化圆锥体树

**数量**：
- 雪堆：20-30 个
- 岩石：10-15 个
- 树木：5-10 棵

#### 2.3 光照系统

**主光源**：
- DirectionalLight3D（模拟阳光）
- 颜色：淡蓝白 (#e6f2ff)
- 角度：45° 斜照
- 阴影：启用，软阴影

**环境光**：
- WorldEnvironment
- 天空：简单渐变（蓝 → 白）
- 雾效：距离雾（增强深度感）

## 🏗️ 技术实现

### 程序化生成系统

**CharacterGeometry.gd** - 角色几何生成器：
```gdscript
class_name CharacterGeometry

static func create_yolk_hero() -> Node3D:
    var root = Node3D.new()
    # 头部、身体、四肢组装
    return root

static func create_enemy(type: String) -> Node3D:
    match type:
        "assassin": return _create_assassin()
        "archer": return _create_archer()
        "guardian": return _create_guardian()
```

**LevelBuilder.gd** - 关卡生成器（已有，扩展）：
```gdscript
func _build_decorations():
    _spawn_snow_piles()
    _spawn_rocks()
    _spawn_trees()
    _apply_terrain_noise()
```

**VFXManager.gd** - 特效管理器：
```gdscript
func play_skill_vfx(skill_id: String, position: Vector3):
    match skill_id:
        "whirlwind": _spawn_whirlwind_vfx(position)
        "dash": _spawn_dash_vfx(position)
        # ...
```
